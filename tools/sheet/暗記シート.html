3 つの式（これだけ）

オームの法則V ＝ I × R　　I ＝ V÷R　　R ＝ V÷I10Ω に 2A → 20V
電力P ＝ V × I ＝ V²÷R ＝ I²×R　→ 電圧を求める：V² ＝ P × R → 平方根25Ω・100W → √2500 ＝ 50V／4Ω・100W → √400 ＝ 20V
波長λ(m) ＝ 300 ÷ f(MHz)150MHz → 2m／21MHz → 14.3m／7MHz → 43m

抵抗のつなぎ方

  • 直列 ＝ 足し算（20Ω＋20Ω ＝ 40Ω）
  • 並列 ＝ 同じ値 2 本なら 半分（20Ω と 20Ω → 10Ω）
  • 並列の一般式 1/R ＝ 1/R₁ ＋ 1/R₂（2 本なら 積÷和）
  • 並列は必ず元の値より 小さく なる

コイルとコンデンサ

  • コンデンサ：直流は 通さない。周波数が 高いほど通す。静電容量が大きいほど通す
  • コイル：周波数が高いほど 通さない（リアクタンス大）。インダクタンスが大きいほど通さない
  • 並列共振：インピーダンス 最大・電流 最小（直列共振は逆）

無線工学 暗記シート ②　電源・電子回路・測定・伝搬・障害 4アマ ながら学習

電源

  • 直列 ＝ 電圧が 足し算（1.5V×4本 ＝ 6V）／並列 ＝ 電圧そのまま、容量が増える
  • 交流 →（整流：ダイオード）→ 脈流 →（平滑回路：コンデンサ・チョークコイル）→ 直流
  • 鉛蓄電池 2V／ニカド・ニッケル水素 1.2V／リチウムイオン 約3.7V
  • リチウムイオン：電圧 高い・自己放電少ない・継ぎ足し充電 できる・発火の危険 ある

電子回路

  • ダイオード ＝ 一方通行 → 整流。電極は アノード・カソード
  • 逆方向電圧で降伏 → 定電圧（ツェナー）ダイオード。バラクタは静電容量が変わる
  • トランジスタ ＝ エミッタ・ベース・コレクタ／FET ＝ ゲート・ドレイン・ソース
  • 乗せるのが 変調、取り出すのが 検波／逓倍 ＝ 周波数を整数倍

測定

  • 電流計は負荷と 直列、電圧計は 並列
  • 分流器（電流計に並列）の倍率 ＝ 1 ＋ 内部抵抗÷分流器の抵抗（1/4 → 5倍）
  • 完全に整合 → SWR ＝ 1。SWRメータで測るのは 定在波比
  • ディップメータ ＝ 同調回路の 共振周波数／擬似負荷 ＝ 電波を出さずに調整

電波伝搬

  • 電離層は低い方から D → E → F（80 / 100 / 200〜400km）
  • 短波の遠距離通信は F層 の反射／D層 は昼間に低い周波数を 吸収
  • VHF・UHF は電離層を突き抜け、直接波で見通し距離内
  • スポラディックE層：夏の昼間、VHF（50MHz帯） を反射 → 遠距離に届く／混信

電波障害

高調波送信周波数の整数倍で必ず 高い。28MHz×3 ＝ 84MHz → FM放送（76〜95MHz）に混信
高調波の対策送信機のアンテナ端子と給電線の間に 低域フィルタ（LPF）（HPF は間違い）。TVI も同じ
基本波が地デジのブースタに入る受信側（地デジアンテナとブースタの間）に トラップフィルタ（BEF）
混変調強い妨害波の変調が希望波に 乗り移る → BCI

無線工学 暗記シート ③　送信機・受信機 4アマ ながら学習

変調方式

AM（A3E）振幅 を変える。側波帯が上下 2 つ
SSB（J3E）片側の側波帯だけ → 帯域は AM の 約半分。搬送波なし
FM（F3E）周波数 を変える。振幅一定 → 雑音に 強い。帯域は AM より 広い
  • 変調度 ＝（最大振幅 − 搬送波）÷ 搬送波　（90V・60V → 50%）
  • 100% 超 ＝ 過変調 → ひずみ・帯域が広がり混信
  • 平衡変調器の出力 ＝ 搬送波 ± 信号波（1506.5＋1.5 ＝ 1508.0kHz）

送信機の回路

ALCSSB：電力増幅器 の入力を制限 → ひずまない
IDCFM：周波数偏移 を一定値以下に（瞬時偏移制御）
VOX声の有無 で送信⇔受信を自動切替
直接FM の構成音声 → IDC → 電圧制御発振器 → 緩衝増幅器 → 電力増幅器 → LPF → アンテナ
AGC・スケルチは受信機の回路

スーパヘテロダイン受信機

  • 流れ：高周波増幅 → 周波数変換（＋局部発振器）→ 中間周波増幅 → 検波 → 低周波増幅
  • 受信周波数と局発の 差 ＝ 中間周波数（IF）。145MHz と 155.7MHz → IF 10.7MHz
  • 高周波増幅部 を設ける → 信号対雑音比 が良くなる／選択度を決めるのは 中間周波増幅器／局発は スプリアスが少ない こと
  • 影像周波数 ＝ 受信 ＋ IF×2（局発が上のとき）＝ 145 ＋ 21.4 ＝ 166.4MHz

受信機の回路 ― キーワードで選ぶ

スケルチ受信電波が ないとき の「ザー」を消す
リミッタFM の 振幅を一定 にして雑音を除く
周波数弁別器周波数の変化 → 振幅の変化（FM の検波器）

法規 暗記シート　数字とキーワード 4アマ ながら学習

数字

無線局の免許の有効期間5 年従事者免許は無期限
再免許の申請満了前 1 か月以上 1 年以内旧：6 か月以内。「1 か月以上」で始まる選択肢
免許証（人）の返納10 日以内取消し・再交付後に発見・死亡／失そう
免許状（局）の返納1 か月以内免許記録の写しは「廃棄」
運用の停止／業務従事停止3 か月以内違反したとき
「本日は晴天なり」＋呼出符号10 秒試験電波
応答がないときの再開間隔3 分
長時間送信中の呼出符号10 分ごと
4アマの電力30MHz超 20W ／ ほか 10W10・14・18MHz 帯は操作できない。モールスの通信操作も含まれない

呼出しと応答

  • 呼出し：相手 3回以下 → こちらは 1回 → 自局 3回以下
  • 応答：相手 3回以下 → こちらは 1回 → 自局 1回
  • 非常：呼出しは前に「非常」3回／応答は次に「非常」1回
  • 電波の型式：A＝AM、J＝SSB、F＝FM／3＝アナログ／E＝電話。A3E・J3E・F3E・A1A（モールス）

キーワード

  • 電波法の目的：公平かつ能率的な利用・公共の福祉を増進
  • アマチュア業務：金銭上の利益のためでなく・自己訓練、通信及び技術的研究
  • 無線局 ＝ 設備 ＋ 操作する者の総体（受信のみは含まない）
  • 事前に 許可：設置場所の変更・変更の工事 の 2 つだけ
  • 報告先はいつも 総務大臣（非常通信を行った／違反局を見つけた）
  • 試験電波：聴守して混信を与えないことを確認・擬似空中線回路
  • 暗語 ✕／特定の相手方の通信を 漏らす・窃用 ✕／他人の依頼の通報 ✕／放送に支障 → 速やかに中止
  • 移動する局の免許状 → 無線設備の常置場所／発射の制限 ＝ 占有する 周波数帯幅
